# Interbus — Propuesta de Rediseño Web

Propuesta de rediseño y modernización del sitio web de Interbus.

El objetivo del proyecto es mejorar la experiencia de los pasajeros,
manteniendo la información y los servicios existentes, pero ofreciendo
una navegación más clara, moderna y adaptable a dispositivos móviles.

## Características

- Diseño responsive
- Navegación optimizada
- Horarios de Acebal, Álvarez y Uranga
- Recorridos y paradas
- Tarifas
- Información SUBE
- Aplicación ¿Cuándo llega?
- Formulario de contacto
- Sector para choferes
- Sector para taller
- Información institucional

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Estado

En desarrollo.

> Este repositorio corresponde a una propuesta de rediseño
> independiente y no constituye el sitio oficial de Interbus.
