Política de privacidad

Protección contra el spam con Google reCAPTCHA

Hemos implementado Google reCAPTCHA en formularios en nuestro sitio web para verificar si los datos ingresados en los formularios provienen de visitantes humanos o de máquinas o programas automatizados, también conocidos como "bots". Esta herramienta analiza automáticamente el comportamiento de los visitantes del sitio web tan pronto como interactúan con él, utilizando diversas informaciones como la dirección IP, la duración de la visita y los movimientos del ratón. Los datos procesados incluyen datos de uso como el sitio web al que se accede, la fecha y hora de acceso y los movimientos del ratón, así como datos de comunicación como direcciones IP, tipo de navegador y sistema operativo. Este procesamiento está dirigido a los visitantes del sitio web y a los usuarios de servicios en línea. El principal objetivo de este procesamiento es prevenir el mal uso de nuestro formulario de contacto, mejorando así la seguridad. La base legal para esto es nuestro interés legítimo según el Art. 6 para. 1 p. 1 lit. f. GDPR. Los destinatarios de los datos incluyen a Google Ireland Ltd, con sede en Google Building Gordon House, Barrow St, Dublin 4, Irlanda, ( https://policies.google.com/privacy ) y nuestro proveedor de hosting de sitios web. Mientras sus datos personales se procesan dentro de la UE, el tiempo de retención para los datos procesados es determinado por Google Ireland Limited. Puede encontrar información adicional en la política de privacidad de Google reCAPTCHA: https://policies.google.com/privacy

Análisis del sitio web (Creator Statistics)

Cuando visitas nuestro sitio web, recopilamos información sobre tu uso a través de una herramienta de análisis web proporcionada por nuestro servicio de alojamiento. Esta herramienta recopila y combina tu dirección IP y tu agente de usuario, los acorta y almacena estos datos utilizando una función hash. Este proceso crea un identificador de visitante cifrado con un valor generado aleatoriamente (SALT) que cambia cada 24 horas. Este método garantiza que tu dirección IP no pueda reconstruirse a partir del identificador de visitante almacenado, manteniendo así tu anonimato. Además, no fusionamos esta información con ningún otro dato y sólo se almacena en el servidor del proveedor de alojamiento.

También procesamos datos de análisis web, datos HTTP y datos de perfil de análisis web. La herramienta de análisis web que utilizamos crea y almacena un perfil de análisis web, que incluye detalles sobre tu uso del sitio web, como páginas vistas, frecuencia de visitas, tiempo empleado en cada página y el agente de usuario de tu dispositivo. Esto incluye datos de uso (como páginas web visitadas y tiempos de acceso) y datos de comunicación (como tipo de navegador, sistema operativo y direcciones IP).

Nuestro propósito al procesar estos datos es analizar el comportamiento del usuario de forma agregada para mejorar la presentación y el contenido del sitio web. La base jurídica de este tratamiento es nuestro interés legítimo (Art. 6 párr. 1 lit. (f) GDPR), en particular para realizar mediciones web con el fin de mejorar nuestros productos y nuestro sitio web.

Los datos recogidos se comparten con nuestro proveedor de alojamiento web y se procesan dentro de la UE.
